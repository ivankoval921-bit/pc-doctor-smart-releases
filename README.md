# PC Doctor Smart

**Developer: Volodymyr Ilchenko**

Лёгкая бесплатная программа для очистки и обслуживания Windows 10/11.
A light, free tool to clean and maintain Windows 10/11.

## Что умеет (версия 1.0)

- **Очистка мусора Windows** — временные файлы, отчёты об ошибках, старые загрузки Windows Update, кэш видеокарты, журналы, корзина (по желанию).
- **Браузеры без выхода из аккаунтов (мягкая очистка)** — Chrome, Edge, Brave, Vivaldi, Opera, Яндекс, Firefox, все профили. Удаляется только кэш; cookies, входы, пароли, история и закладки остаются.
- **Жёсткая очистка браузеров** — по выбору: история, cookies, сессии. Пароли и закладки остаются.
- **Аварийная кнопка «Стереть следы»** — закрывает браузеры и стирает историю, cookies, сессии, недавние файлы Windows (двойное подтверждение).
- **Кэш программ** — Telegram, Discord, Spotify, VS Code, Steam, Claude Desktop, Teams, Zoom.
- **Точки восстановления** — создать одной кнопкой, откатить, ограничить место, еженедельная точка.
- **Автоматизация** — ночная уборка при простое, еженедельная точка, ежедневная проверка обновлений. Всё невидимо и с самым низким приоритетом; останавливается при движении мыши.
- **Автообновление** — новая версия приходит сама, один клик «Обновить».
- **6 тем** (тёмная, светлая, зелёная, морская, графит, тёплая) и **5 языков** (русский, українська, Deutsch, English, Polski).
- **Встроенная справка** — кнопка «?» на каждой странице.

Скоро: реестр, автозагрузка, деинсталлятор с хвостами, твики, облака.

## Установка

1. Скачайте `PCDoctorSmart.exe` со страницы [Releases](https://github.com/ivankoval921-bit/pc-doctor-smart-releases/releases/latest).
2. Положите в любую папку (например `D:\Programs\PCDoctorSmart`) и запустите. Установка не нужна.
3. Нужен **.NET 8 Desktop Runtime**. Если его нет, Windows сама предложит скачать при первом запуске.

Программа просит права администратора — без них нельзя чистить системные папки и создавать точки восстановления.

Подробное руководство: [docs/USER_GUIDE.ru.md](docs/USER_GUIDE.ru.md).

## Конфиденциальность

Программа ничего не отправляет в интернет, кроме запроса к GitHub для проверки новой версии. Настройки и журналы лежат в папке `data` рядом с программой.
